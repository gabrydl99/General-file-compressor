**Windows** — download `General-File-Compressor-Windows.zip`, extract it and open `General File Compressor.exe`. If SmartScreen warns, click **More info → Run anyway** (the exe isn't signed). Keep the `_internal` folder next to the exe. To update, extract the new zip over the old folder.

**Android** — download `General-File-Compressor-Android.apk` on the phone and open it. Allow installing from this source when asked; if Play Protect warns, choose **Install anyway** (the app isn't on the Play Store). On first start, tap **Allow** on the "Allow access to all files" card.

Both apps look for a newer release at start-up and offer to update (on Android the app downloads and installs it).

### New in 1.2.0

- Update check at start-up on Windows and Android.
- Since 1.1.0 (Windows): retry button next to "Why did it fail?", Discord size chip.
- Both apps are built and tested by GitHub Actions.
